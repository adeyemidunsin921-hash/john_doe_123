# Telegram Bot @john_doe_123bot

A multifunctional Telegram bot with various features.

## 🚀 Features

- **Word Counter** - Count words, characters, and sentences
- **URL Shortener** - Shorten long URLs
- **Echo** - Make the bot repeat your message
- **Interactive Buttons** - Clickable menu for easy access

## 🛠️ Tech Stack

- Python 3.9+
- python-telegram-bot v20+
- Railway for hosting
- GitHub for version control
